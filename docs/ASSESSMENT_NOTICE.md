# Assessment Notice

Repository ini dibuat untuk technical assessment Portal Warga. Isi source dan dokumentasi disediakan untuk evaluasi teknis, bukan sebagai paket open-source.

Tidak ada lisensi open-source yang diberikan. Jangan menganggap izin untuk menyalin, mendistribusikan, memublikasikan, atau menggunakan source di luar tujuan assessment. Tidak ada remote atau URL GitHub yang dinyatakan oleh dokumen ini.

Data, akun, URL, dan credential pada environment lokal harus diperlakukan sebagai informasi privat. Gunakan `.env.example` sebagai daftar konfigurasi; jangan memublikasikan `.env`.
